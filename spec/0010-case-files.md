# 0010 대표 사례 페이지 — 명세

- 의도: `intent/0010-case-files.md`

## 1. 주소와 메뉴
- `/cases` 한 페이지. 상단 내비게이션 첫 자리에 "대표 사례"를 둔다.
- 페이지가 보이지 않는 빌드(승인 전 운영 빌드)에서는 경로와 메뉴를 만들지 않는다.

## 2. 저장
- `src/content/cases.ts`: `CASES_STATE`(`draft` | `published`), `CASES_UPDATED`, `CASES`(유형 3개).
- 항목: `type`(유형 이름), `record`(대표 증거 id), `caption`(2줄 이내, 60자 이하, "제보."로 끝남).

## 3. 페이지 구성
1. H1 "대표 사례", 첫 문단 안내.
2. 대표 증거가 모두 문서 확인·영상 확인이 아니면 "운영진이 아직 확인하지 않은 제보"를 표시한다. 면책 문장을 둔다.
3. 유형마다: 유형 이름(H2), 대표 증거의 첫 사진(누르면 증거 상세), 설명, 날짜·장소·상태·"증거 보기".
- 데이터에 없는 증거(비공개로 바뀐 기록)는 빼고 그린다.

## 4. 초안과 공개
- `draft`는 빌드 환경 `VERCEL_ENV=preview`(Vercel PR 미리보기) 또는 `CASE_DRAFTS=1`(CI·로컬)일 때만 나온다.
- 초안에는 `noindex`를 달고, 사이트맵과 llms.txt에 넣지 않는다. 화면 위에 "승인 전 초안"을 표시한다.
- 운영자가 승인하면 `CASES_STATE`를 `published`로 바꿔 머지한다.

## 5. 완료 기준
- [ ] 미리보기에서 `/cases` 초안이 열리고, 운영 빌드에는 없다.
- [ ] 운영자가 유형과 사진을 승인한다.
