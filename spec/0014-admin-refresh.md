# 0014 관리 화면 정리 — 명세

- 의도: `intent/0014-admin-refresh.md`

## 1. 목록에서 상태 바꾸기
- 기록 행마다 [자료 확인 | 제보] 두 칸 버튼을 둔다. 공개·비공개 버튼 옆이다.
- 자료 확인을 누르면 장소와 매체(사진·영상·문서)를 검사한다. 없으면 바꾸지 않고 이유를 위에 알린다.
- 목록 위 요약: "총 N건 · 공개 N건 · 자료 확인 N건".
- 목록 위에 상태 거르기(전체·자료 확인·제보)를 둔다.

## 2. 디자인
- 공개 화면 토큰(`.desk`의 배경·글자·구분선·상태 네 색)을 쓴다. 관리 화면 루트에 `desk adm` 클래스를 단다.
- 버튼: 구분선 색 테두리, 4px 모서리. 주 버튼(저장, 로그인, 선택된 칸)은 글자색 바탕에 배경색 글자.
- 위험 동작(삭제, 기각, 비공개 선택)은 상태색을 쓴다.
- 행과 카드는 둥근 상자와 그림자 대신 위아래 구분선으로 나눈다.
- 스타일은 `src/styles/admin.css`에 둔다. 관리 화면 코드만 불러온다.

## 3. 문체
- 관리 화면의 안내·오류·확인 문구를 합니다체로 쓴다.

## 4. 자료 다 보기(운영자 요청, 2026-10-25)
- 편집 창에 영상·음성(`media_other`)을 바로 재생하는 칸을 둔다. 원본이 없는 항목은 "유실"로 적는다. 항목을 뺄 수 있다.
- 목록 한 줄에 "사진 N · 영상 N · 음성 N · 비공개 원본 N"을 적는다.
- 개인정보 때문에 공개하지 않은 원본(`withheld`)은 저장소에 없다. 이번 범위에서 올리지 않는다(비식별 전 자료를 서버에 두는 일이라 운영자 결정이 필요하다).
