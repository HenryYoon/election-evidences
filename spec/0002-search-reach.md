# 0002 검색·AI 도달 — 명세

- 의도: `intent/0002-search-reach.md`
- 이 문서는 `spec/0001-evidence-desk.md` 6장의 "JSON-LD와 `llms.txt`는 정리용이다. 인용 증가 수단으로 먼저 하지 않는다"를 바꾼다. 회수 기반이 갖춰졌으므로 `llms.txt`와 마크다운을 지금 만든다. JSON-LD는 계속 뒤로 둔다.
- 참고: Addy Osmani, "Agentic Engine Optimization"(2026-04)과 감사 도구 agentic-seo. 사이트와 맞는 항목만 쓴다.

## 1. 가벼운 HTML
- 홈과 기록 목록의 데이터 스냅샷을 HTML 밖 파일로 뺀다. 파일 이름에 내용 해시를 넣는다. HTML에는 파일 주소만 둔다.
- 상세 페이지는 스냅샷이 작아 HTML 안에 둔다.
- 지도 경계선은 빌드 때 만든 정적 SVG 파일로 뺀다. 페이지 SVG에는 점(기록 링크)만 둔다.
- 예산: 홈과 기록 목록 HTML은 각각 40KB 이하, 상세 HTML은 10KB 이하.

## 2. `llms.txt`
- 사이트 루트에 둔다. 빌드 때 공개 데이터로 만든다.
- 순서: 사이트 이름(H1), 한 줄 요약(인용 블록), 상태 정의와 "상태는 조사 분류이며 법적 결론이 아니다", 층 설명과 주소, 기록 목록.
- 기록 한 줄: `- [주장](마크다운 주소): 날짜, 장소. 상태 X. 출처 Y.`
- 비공개 기록, 제보 원문, 이름, 연락처는 넣지 않는다.

## 3. 기록별 마크다운
- 공개 기록마다 `/e/<id>.md`를 만든다.
- 내용: H1 주장, 첫 문단(상세 첫 문장과 같다), 사실 목록(상태, 좌표, 선거, 유형. 좌표는 상세 화면과 같이 "위도, 경도" 순으로 쓴다), 검증 네 줄, 제보 내용, 출처, HTML 주소.
- 상세 HTML 머리에 `<link rel="alternate" type="text/markdown" href="/e/<id>.md">`를 둔다.
- 상세 화면에 마크다운 링크를 둔다.

## 4. 인용 복사
- 상세 화면에 "인용 복사" 버튼을 둔다. 첫 문장, 출처, 주소를 일반 텍스트로 클립보드에 넣는다.
- JS가 없으면 버튼은 동작하지 않는다. 같은 정보는 본문과 마크다운에 이미 있다.

## 5. robots.txt
- 모두 허용(`User-agent: *`)을 유지한다.
- 주요 AI 크롤러를 이름으로 허용한다: GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, Claude-User, PerplexityBot, Google-Extended.
- `/admin`은 모두에게 막는다.

## 6. 메타
- `og:type`(상세 `article`, 나머지 `website`), `og:title`, `og:description`, `og:url`을 둔다. 링크 공유 미리보기에도 쓰인다.
- 토큰 수 메타처럼 표준이 아닌 태그는 두지 않는다.

## 7. 주기 점검
- GitHub Actions 작업 하나를 주 1회와 수동 실행으로 돌린다. 대상은 운영 사이트다.
- 점검 1, 실제 사이트 회수: 홈, 층 목록, 사이트맵의 상세 일부를 JS 없이 받아 title, description, canonical, H1 하나, 첫 문단, HTML 예산을 본다. `/ledger`와 `/e/ev-009` 리다이렉트, `llms.txt`, 마크다운 하나를 본다.
- 점검 2, Lighthouse: 홈, 기록 목록, 상세 하나. 성능, 접근성, 모범 사례, SEO 네 범주. 기준 미달은 실패다.
- 점검 3, agentic-seo: 운영 사이트 주소로 감사한다. 점수를 기록하고 기준 미달은 실패다.
- 기준값은 첫 측정 뒤 플랜에 적는다. 떨어지면 실패로 드러나고, 올릴 때만 기준을 고친다.

## 8. 완료 기준
- [ ] 홈과 기록 목록 HTML이 40KB 이하다.
- [ ] `llms.txt`와 모든 공개 기록의 마크다운이 있고, 개인정보 검사를 통과한다.
- [ ] 상세에 마크다운 링크와 인용 복사 버튼이 있다.
- [ ] 주기 점검 작업이 운영 사이트에서 한 번 이상 통과한다.
