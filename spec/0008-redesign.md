# 0008 개편 — 명세

- 의도: `intent/0008-redesign.md`
- 이 문서는 `spec/0001-evidence-desk.md`의 다음 규칙을 바꾼다. 바뀐 규칙은 이 문서가 우선한다.
  - 1장 네 층 → 두 층(증거, 제보). 통계와 피드는 없앤다.
  - 2장 "홈에 층별 건수를 큰 숫자로 노출" 금지 → 홈에 수집 건수와 검증 건수를 보여 준다. 층이 하나뿐이라 건수가 섞이지 않는다.
  - 5장 홈 "콘텐츠를 펼치지 않는다" → 아래 1장대로 한다.
  - 5장 상세 오른쪽 "좌표" → 보여 주지 않는다. 마크다운에도 쓰지 않는다.
  - 층 이름 "기록" → "증거". 주소 `/records`, `/e/:id`는 유지한다.

## 1. 이름
- 사이트 이름: 선거부정진상규명국민신고센터. 줄임말: 선진국. 영어: Citizen Report Center for Election Integrity (SeonJinGuk).
- 상단 바 왼쪽 표시는 "선진국"이다. 브라우저 제목, 검색 설명, JSON-LD, `llms.txt`, 인용 복사, 문의 메일 제목이 같은 이름을 쓴다.

## 2. 홈 `/`, `/en`
- 위에서 아래 순서:
  1. 이름(H1). 중앙 정렬, 큰 글자(운영자 결정, 2026-10-25: 이름 아래 부제는 두지 않는다).
  2. 숫자 두 개, 중앙 정렬: "수집 N건", "검증 N건". 수집은 공개 증거 수다. 검증은 상태가 문서 확인 또는 영상 확인인 증거 수다. 0건이어도 그대로 보여 준다(운영자 결정).
  3. 면책 문장 한 줄, 작은 글자.
  4. 왼쪽 지도, 오른쪽 최근 증거 세 줄(기존).
  5. 입구 링크 두 개: "2026 지방선거 증거 보기", "제보하기". 설명 글은 없다.
- 목적 문장, 세 단계, 층 설명은 홈에서 뺀다. 소개 페이지에는 남긴다.

## 3. 증거 `/records`, `/e/:id`
- 목록 H1: "2026 지방선거 증거". 첫 문단은 "2026 지방선거(2026-06-03) 사전투표·본투표·개표 과정의 사진, 영상, 문서."로 시작한다.
- 상세 오른쪽: 상태, 선거, 유형. 좌표는 없다. 마크다운 사실 목록에서도 좌표를 뺀다.
- 상세 아래 링크: "증거 목록으로".

## 4. 통계·피드 제거
- 상단 메뉴, 홈, 소개, `llms.txt`, 사이트맵에서 뺀다.
- `/stats`, `/feed`는 홈으로 영구 리다이렉트한다.
- 페이지 파일과 통계 제외 항목 상수는 지운다.

## 5. 제보 폼
- 파일 업로드 칸을 링크 칸보다 위에 둔다. 링크 칸은 큰 파일용이다(운영자 결정, 2026-10-25).
- 안내 목록을 한 줄로 줄인다: "사진·영상·문서 파일 5개(파일당 20MB)까지. 이름과 연락처는 선택이다."
- 동의 세 칸은 각각 체크박스 한 줄과 괄호 요약으로 보인다. 법정 고지 전문은 "자세히" 접힘 안에 둔다. 접힘은 처음에 닫혀 있다.
  - 필수 수집·이용: "제보 내용·첨부 파일·접속 기록을 받습니다. 최대 1년 보관."
  - 필수 국외 이전: "저장소가 호주(Supabase)에 있습니다."
  - 선택 이름·연락처: "사실 확인 연락에만 씁니다. 검수 뒤 삭제."
- 처리방침 링크는 그대로 둔다.

## 6. 민간 운영 표시
- 페이지 아래에 "민간 시민이 운영하는 사이트입니다. 선거관리위원회 등 공공기관과 관계가 없습니다."를 둔다.
- 소개 첫 문단 뒤에 같은 뜻의 문장을 둔다. 영어판도 같다.
