# 0013 검증 네 줄을 공개 화면에서 뺀다

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-25)
- 다음 단계: `spec/0013-drop-verification-lines.md`
- 앞 문서: `intent/0012-polite-style.md`

## 문제
- 증거 상세에 "검증" 네 줄(보인 것, 장소, 시각, 주장하지 않는 것)이 있다. 95건 모두 비어 있어 "미기재"가 반복된다.
- 빈 칸이 반복되면 사이트가 확인 작업을 하지 않은 것처럼 보인다.

## 기대 결과
- 검증 네 줄을 지우거나 채운다(운영자, 2026-10-25). Claude는 지우기를 권했다. 채우려면 94건을 운영자가 한 줄씩 써야 하고, 자동으로 채우면 장소·설명을 옮겨 적는 것에 그친다. 0011의 "자료 확인" 상태가 같은 역할을 한다.
- 상세, 마크다운, 소개, 관리 화면에서 뺀다. DB 칸(`verification`)은 남겨 다시 쓸 길을 둔다.
