# 0009 Supabase 서울 리전 이전과 저장소 연동

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-25)
- 다음 단계: `spec/0009-seoul-region.md`
- 앞 문서: `intent/0008-redesign.md`

## 문제
- 제보 내용, 연락처, 첨부 파일이 호주(시드니) 서버에 저장된다. 그래서 제보 폼이 국외 이전 동의를 따로 받는다.
- 스키마 변경을 운영자가 SQL 편집기에서 손으로 실행한다. 적용을 빠뜨린 적이 있다(0007, 0008).

## 기대 결과
- 데이터를 서울(ap-northeast-2) 프로젝트로 옮긴다. 제보 폼에서 국외 이전 동의를 뺀다(운영자 결정, 2026-10-25).
- 저장소를 Supabase GitHub 연동으로 새 프로젝트에 연결한다. main에 머지된 마이그레이션은 자동으로 적용된다.

## 제약
- 문의 메일(Resend, 미국)과 사이트 전송(Vercel, 미국)은 국외에 남는다. 문의 폼의 국외 이전 동의와 처리방침의 공개는 유지한다.
- 기존 시드니 프로젝트에는 저장소를 연결하지 않는다. 마이그레이션 기록이 비어 있어 전체가 다시 실행된다.
- 전환 중 독자 쪽 중단이 없어야 한다.
