# 0006 문의 페이지

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-11)
- 다음 단계: `spec/0006-contact.md`
- 앞 문서: `intent/0005-privacy-consent.md`

## 문제
- 건의, 문의, 정정 요청, 개인정보 요청을 받을 창구가 없다. 지금은 제보 폼을 대신 쓰게 안내한다.
- 처리방침의 보호책임자 연락 창구가 제보 폼이다. 제보와 문의가 섞인다.

## 기대 결과
- `/contact` 문의 폼으로 받은 내용이 운영자 이메일로 온다.
- 운영자 이메일 주소는 화면과 저장소 어디에도 나오지 않는다.
- 처리방침과 소개의 요청 창구가 문의 페이지가 된다.

## 제약
- 메일 발송은 Resend로 한다(운영자 결정, 2026-10-11). Resend는 미국 업체라서 국외 이전 고지와 동의가 필요하다.
- 받는 주소와 API 키는 Vercel 서버 환경변수에만 둔다.
- 남용을 막는다. 같은 사람의 반복 전송을 제한한다.
