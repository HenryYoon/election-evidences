# 0010 정리 페이지

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-25)
- 다음 단계: `spec/0010-case-files.md`
- 앞 문서: `intent/0009-seoul-region.md`

## 문제
- 외부 피드백: "목적이 안 보이고 데이터만 나열된 느낌이다"(0004, 0008). 증거 목록만으로는 무슨 일이 있었는지 한눈에 보이지 않는다.
- SNS에 주기적으로 공유할 계획이다. 증거 1건보다 같은 종류의 증거를 묶은 페이지가 공유 단위로 낫다.

## 기대 결과
- 같은 종류의 의혹을 묶어 설명하는 "정리" 페이지가 생긴다. 묶는 단위는 사건·유형이다(운영자 결정, 2026-10-25).
- 첫 주제는 "투표함 봉인지 이상"이다(운영자 결정, 2026-10-25).
- 글은 Claude가 기록 내용만으로 초안을 쓰고, 운영자가 고쳐서 승인한다(운영자 결정, 2026-10-25).

## 제약
- 정리 글은 운영자가 직접 쓰는 주장이다. 허위사실 공표와 명예훼손 위험이 증거 목록보다 크다. 문장마다 근거 증거를 연결하고, 제보 내용과 운영진이 확인한 사실을 나눠 쓴다.
- 검증 상태는 연결된 증거의 상태에서 자동으로 계산한다. 글에 손으로 적지 않는다.
- 국적이나 민족을 추정하는 주장은 옮기지 않는다.
- 승인 전 초안은 운영 사이트에 공개하지 않는다.
