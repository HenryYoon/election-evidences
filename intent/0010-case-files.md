# 0010 대표 사례 페이지

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-25)
- 다음 단계: `spec/0010-case-files.md`
- 앞 문서: `intent/0009-seoul-region.md`

## 문제
- 외부 피드백: "목적이 안 보이고 데이터만 나열된 느낌이다"(0004, 0008). 증거 목록만으로는 어떤 일이 제보됐는지 한눈에 보이지 않는다.
- SNS에 주기적으로 공유할 계획이다. 한눈에 보이는 공유 단위가 필요하다.

## 기대 결과
- 대표 유형 3개를 정하고, 유형마다 대표 증거 1건을 사진과 2줄 이내 설명으로 보여 주는 페이지가 생긴다(운영자 결정, 2026-10-25).
- 긴 정리 글은 쓰지 않는다(운영자 결정, 2026-10-25. 첫 초안의 긴 글 형식을 바꿨다).
- 유형과 사례는 Claude가 기록 내용으로 제안하고, 운영자가 미리보기에서 보고 승인한다.

## 제약
- 대표로 고른 것 자체가 강조다. 설명은 사진에 보이는 사실만 쓰고 "~라는 제보"로 끝낸다.
- 검증 상태는 증거 데이터에서 붙인다. 설명에 손으로 적지 않는다.
- 승인 전 초안은 운영 사이트에 공개하지 않는다.
