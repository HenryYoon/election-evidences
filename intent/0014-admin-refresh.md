# 0014 관리 화면: 상태 바로 바꾸기, 디자인·문체 맞추기

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-25)
- 다음 단계: `spec/0014-admin-refresh.md`
- 앞 문서: `intent/0013-drop-verification-lines.md`

## 문제
- 상태(자료 확인·제보)를 바꾸려면 기록을 하나씩 열어 편집 창에서 골라야 한다.
- 관리 화면이 옛 사이트 디자인(남색·청록 버튼, 둥근 카드, 그림자)을 그대로 쓴다. 공개 화면(0008)과 결이 다르다.
- 관리 화면 문구가 한다체다. 공개 화면은 합니다체로 바꿨다(0012).

## 기대 결과
- 기록 목록에서 공개·비공개처럼 상태도 한 번에 바꾼다(운영자 요청, 2026-10-25).
- 관리 화면이 공개 화면의 서체 하나, 색 네 가지 규칙을 따른다.
- 관리 화면 문구를 합니다체로 바꾼다.

## 제약
- 자료 확인은 장소와 매체가 있어야 한다(0011). 목록에서 바꿀 때도 같은 조건을 검사한다.
- 상태는 운영자가 직접 누를 때만 바뀐다. 일괄 자동 변경 기능은 만들지 않는다.
