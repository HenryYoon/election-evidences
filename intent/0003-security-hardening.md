# 0003 보안 점검과 보강

- 작성자: 윤희승
- 상태: 승인됨 (2026-10-10)
- 다음 단계: `spec/0003-security-hardening.md`
- 앞 문서: `intent/0002-search-reach.md`

## 문제
- Search Console에 사이트를 등록했다. 검색에 노출되면 자동화된 공격 요청이 늘어난다.
- 공개 경로는 정적 HTML, Supabase 공개 API(anon 키), 제보 접수 RPC, 관리자 재빌드 API 네 곳이다.
- 운영자가 공개 전에 위 네 곳을 점검하라고 요청했다(2026-10-10).

## 기대 결과
- 공격자가 공개 경로로 비공개 자료(제보 원문, 이름, 연락처, 비공개 기록)를 읽지 못한다.
- 공격자가 비율 제한을 헤더 위조로 우회하지 못한다.
- 사이트가 기본 보안 헤더를 보낸다.

## 영향 받는 사용자와 시스템
- 운영자: 관리자 화면, Supabase 인증 설정.
- 시스템: `vercel.json`, Supabase 함수와 스토리지 정책, `scripts/reach/check-live.mjs`.

## 제약
- 공개 사진·영상 주소는 그대로 동작해야 한다.
- 화면과 사전 렌더링 결과는 바꾸지 않는다.
